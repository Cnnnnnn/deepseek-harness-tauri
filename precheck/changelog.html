1.0.15 封装改进

相对此前未发布的 1.0.14 本地构建，补上了升级链路与排障/安全收紧。

01

一键升级 dsh

运行版本与固定目标版本不一致时自动弹出升级窗口，也可从菜单「工具 → 升级 dsh…」随时打开；升级会执行 npm 全局安装、清缓存并重启子进程。

02

保留 dsh stderr

子进程 stderr 不再丢弃，崩溃或启动失败时以 [dsh:err] 前缀写入 install.log，便于定位问题。

03

收紧主窗口导航

内嵌页面仅允许访问 http://127.0.0.1 且端口必须等于本次 dsh 监听端口，避免被导航到同机其它服务。

0.1.6-alpha.1 新增能力

本次从 0.1.5-rc.2 升级到 0.1.6-alpha.1，上游带来的主要变化。

01

侧边栏终端

Web 侧边栏新增终端，支持多标签、Shell 选择，刷新后可恢复会话。

02

已归档会话

设置中新增已归档会话列表，支持查看和恢复；同时修复会话最近更新的排序，新建空白会话置顶。

03

MCP 资源能力

支持发现和读取 MCP 资源、使用 URI 模板；MCP 升级至官方 SDK v2，支持协议协商与工具分页。内置 Profile 配置 MCP 服务器后即可使用共享资源工具。

04

Headless 与远端工作区

Headless 支持从标准输入接收任务，用 --session-id 继续已有会话，用 --json 逐行输出运行事件；扩展文件、命令及 PTC 工具，可通过 SSH 使用远端工作区。

05

实验性 Browser Use

新增实验性浏览器操作支持，包含 Playwright MCP、Chrome DevTools MCP 和 Stagehand 浏览器后端。

06

实验性 Computer Use

新增实验性本机操作支持，可通过 Cua Driver MCP 或原生驱动操作本机并获取截图。

07

实验性 Auto review

新增实验性自动评审模式。

08

流式与文件预览优化

文件、Skill 引用及交付文件链接默认由侧边栏预览；预览保留文件树滚动位置，图片和 PDF 随面板适配；Trajectory 支持展开和复制 JSON 字符串、查看 PTC 代码及调用结果。

DeepSeek Harness 上游更新

以下是从 0.1.2-rc.1 升级到 0.1.5-rc.2 期间，上游版本带来的主要变化。

RC

DeepSeek-V41-Flash 模型

新增 DeepSeek-V41-Flash（deepseek-flash），支持文本、图片及会话历史中的系统提示词更新；显式配置的模型保持优先。

01

通用文件上传与预览

Web 支持上传任意类型的通用文件，文件和图片可在同一预览区混排；后台上传显示进度、支持取消，并可在切换会话后继续查看。

02

Sidebar 工作区预览

右侧 Sidebar 支持多标签、分栏和全屏，预览 Markdown、代码、HTML、PDF 和图片，并可用默认应用打开或在文件管理器中定位。

03

动态系统提示词与模型探测

支持在不破坏 KV Cache 的前提下动态修改系统提示词；自定义 provider 支持 models 对象和 Anthropic 原生模型列表。

04

连接、代理和反馈

所有出站请求遵循 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY 和 NO_PROXY 环境变量；Web 断线自动恢复；反馈可独立提交，并支持更清晰的发送/排队状态。

05

Session V3 与开发者 API

会话数据升级为 Session V3，旧日志通过相邻版本迁移并保留原文件；Session 生命周期改用 SessionHandle，默认文件工具和插件 API 也同步调整。

06

在应用中打开 Workspace

Web 顶栏新增「在应用中打开」，可用已安装的编辑器、IDE、终端或文件管理器打开当前 Workspace；PTC 模式还可展开命令及输出。

本次升级内容

01

dsh 固定到 alpha.1，并补一键升级

@deepseek-ai/dsh@0.1.6-alpha.1。升级前已实测：首页返回 200，62 个前端资源全部 200，无 404。本机旧版不会再被静默沿用，版本不一致会引导一键升级。

02

兼容新版 Web 认证 URL

读取 dsh 启动时生成的一次性 token URL，内嵌页面可正常打开；dsh 自动重启后也会同步新 token。

03

排障与导航安全

dsh stderr 落盘；主窗口导航锁定本机 http + 固定端口。

兼容提醒

本次目标版本处于 alpha 通道，上游同时包含若干不再兼容的变更，升级前请留意。

!

DeepSeek 默认改用 Messages 协议

自定义 API 地址保留不变；若曾手动配置旧官方根地址，需移除该配置或改为 https://api.deepseek.com/anthropic。

!

PTC 包名与服务名统一

统一为 ptc-runtime 系列，旧名称不再兼容，自定义插件与配置需相应更新。

!

移除内置 E2B 执行后端

相关自定义配置需调整；另外默认不再启用 Ralph，需要时请手动启用。
